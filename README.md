# 📚 Book Review - Django Project

This project is a simple web application for reviewing books, built with Django and Django REST Framework. The admin panel is customized using **Django Suit** to provide a modern and user-friendly interface.

## 🚀 Features

- Add, edit, and delete book entries.
- Admin panel customization using Django Suit.
- REST API integration with `rest_framework` and `simplejwt`.
- Secure user authentication.
- Responsive and clean admin layout.

## 🛠️ Technologies Used

- Django
- Django REST Framework
- Django Suit
- SQLite (default DB)
- Python 3.x
